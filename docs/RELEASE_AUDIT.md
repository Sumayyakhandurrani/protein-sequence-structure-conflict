## Scientific provenance limitation

The archived primary analysis source matches the script digest
recorded in the methodological evidence. However, the original
execution manifest lacks an execution-time script hash or Git commit.
The exact executed source revision therefore remains unauthenticated.

Do not claim complete end-to-end reproduction until independently
tested.
